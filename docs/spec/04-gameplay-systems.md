# 04｜玩法系统

## 1. 统一游戏循环

```text
工坊／聚落整备
  → 选择任务与真实目的地
  → 通过公共交通或步行抵达
  → 建立外出入口快照
  → 实地调查、路线规划、机关解谜自然切换
  → 安全出口提交成果，或主动撤退回滚外出段
  → 获得固定成长／材料／世界变化
  → 返回、回访或继续下一任务
```

三种行动区段共享生命、背包、方块所有权、任务和场景等持久状态。区段可按任务规则临时限制当前可调用的库存，例如机关解谜只使用现场配给；限制不会改写全局背包，离开后原状态保持。切换区段不会治疗、补给、刷新敌人、推进世界步或清除已经提交的环境变化。

## 2. 三种行动区段

| 正式名称 | 日文 | UI短签 | 玩家主要行为 | 核心问题 |
|---|---|---|---|---|
| 路线规划区段 | ルート攻略パート | 路线／ルート | 查看固定地图、比较损耗、配置方块、处理阻拦和资源 | 走哪条路，付出什么代价 |
| 机关解谜区段 | 仕掛け攻略パート | 机关／仕掛け | 观察目标、使用固定配给、放置／旋转／推动、逐步运行机关 | 怎样让规则成立并恢复设施 |
| 实地探索区段 | フィールド探索パート | 探索／探索 | 移动、对话、观察、调查、取证与推进固定剧情 | 发生了什么，为什么行动 |

规则：

- 不从菜单选择“进入模式”；进入相应空间和任务状态后，镜头与HUD自然变化。
- 同一任务可以只使用一种区段，也可以串联多种，不为数量平衡强行切换。
- 确定性接触战属于路线规划，不是第四种战斗模式。
- “秘密探索”只是一种可选内容标签；可以包含三种区段，但没有专属HUD、属性、货币或成长。

## 3. 方格、占位与移动

### 3.1 坐标和占格

- 权威玩法状态使用整数三维坐标；标准方块占 `1×1×1` 格。
- 洛尔、阿莉娅、普通NPC和普通敌人各占一个 `1×1` 落脚格。
- 大型阻拦可以拥有跨格外观，但必须公布核心接触格与固定占用格，不另建自由形状碰撞规则。
- 同一格不能同时容纳两个实体；装饰可以越出格面，但不能改变占格、通行和作用范围。

### 3.2 移动

- 只允许上下左右四方向跨格，不斜向移动。
- 每次合法移动从一个格心结算到相邻格心；动画可以平滑插值。
- 角色不能自由跳上一层；高差通过阶梯、脚手架、升降台或明确的合法连接处理。
- 镜头旋转不改变世界方向；输入相对当前画面重新映射。镜头在任一稳定90°朝向下，W／A／S／D与方向键必须严格对应屏幕上／左／下／右；旋转过渡中收到移动输入时，先完成到目标朝向再执行一格。
- 长按连续逐格移动必须在敌人、危险、未知格、强制移动入口、机关触发格、出口和高差前自动停止。

## 4. 世界步与确定性结算

以下动作推进一个世界步：合法移动、提交放置、回收、提交已部署对象的新朝向、推动、牵引、操作机关、使用补给和主动等待。

查看地图、菜单、放置预览中的朝向调整、帮助、镜头操作、取消、无效输入和剧情对话不推进世界步。

统一结算顺序：

1. 玩家行动及直接拾取／使用结果；
2. 构造响应；
3. 环境带动，包括水流和传送带；
4. 敌人巡逻；
5. 周期环境与时序轮替；
6. 支援联动重新计算；
7. 接触战斗与本步胜负检查。

任一移动阶段形成明确接触后，双方进入“本步接触锁定”：在本步余下的环境带动和巡逻阶段不再发生第二次位移，避免同一接触被水流或路线更新静默改写；周期环境、支援重算和失活检查仍按上述顺序执行。若周期环境先使任一方失活，接触取消并保留此前阶段的结果。此锁定只持续当前世界步，不等同于角色免疫水流或传送带。

每个会推进世界的动作在确认前，显示玩家已知且当前可观测的直接结果。预览不得揭露尚未发现的格、对象、秘密或谜底；进入未知格时只标明“将探索未知格”，完成该步后再更新知识状态。正式地图不得把未知信息与无法撤回的必然重损耗绑定。多个对象争夺同一格时，相关对象全部留在原位；不使用随机优先级，也不得设计成同一步有两名敌人同时接触玩家。

追逐、潜入、护送和灾害仍使用逐格“紧迫步”，不变成实时动作：下一步危险至少提前一格／一阶段显示；观察与菜单暂停；失败返回局部检查点。

## 5. 环境与地形语法

| 地形／状态 | 正式规则 |
|---|---|
| 高差地形／高低差 | 相邻格高度不同且没有阶梯、脚手架或合法连接时不可通行；无坠落伤害 |
| 无地面格／足場のないマス | 不可进入；可用基座或悬台形成地面；不设置掉落伤害 |
| 脆弱地面／もろい床 | 第一个可移动实体离开后变为无地面格；状态公开并持久保存，可通过结构恢复路线 |
| 水流／水流 | 环境阶段沿公开箭头带动实体一格；可停止、反向或以锚桩抵抗 |
| 传送带／コンベア床 | 激活时沿公开方向带动一格；可以停用或反转 |
| 腐蚀地面／腐食床 | 每次进入承受公开固定生命损失；原地停留不重复；不摧毁玩家方块 |
| 外露矿晶／露出鉱晶 | 接触时承受公开固定生命损失；不是采集物和随机掉落 |
| 周期危险区／周期危険区域 | 依公开阶段启闭；进入激活区或脚下阶段变为激活时承受一次固定损失；始终显示当前和下一阶段 |

强制移动目标格无效、被占或受锚定时，实体原地等待；不连锁推动其他实体。当前版本的水流、传送带等环境带动只作用于角色，不会自动移动已经放置的方块；只有未来明确定义的机关或方块机制可以驱动这些方块。环境不能吞掉、摧毁或改变玩家方块所有权。正式地图禁止隐藏即死格、随机扩散和不可预知的永久损失。

## 6. 路线规划区段

### 6.1 标准循环

整备配置 → 查看与规划有关的完整公共布局 → 比较敌人、环境、方块和绕行成本 → 推进世界步 → 到达安全节点／目标 → 安全出口结算。

- 地图完全手工设计，不随机生成。
- 与规划有关的固定敌人、门、公开资源、危险和已知机关入场即可查看；秘密内容仍保持隐藏。
- 大型主线图通常45–70分钟，分3–4个区域和15–25分钟的安全规划单元。
- 每张图至少有两条仅依靠主线保证资源可完成的路线；不存在全方面更优的唯一答案。
- 不要求清空敌人，也不奖励击败数量、最短步数、S/A/B评级或无伤。
- 玩家可在下一动作前撤销上一个世界步；不能跨过目标完成、地图进出、永久奖励、融合确认或剧情提交点。

### 6.2 通行方块／通行ブロック

- 通行方块是地图内的真实特殊方块，放入对应插槽后与环境融合并开启门或路径。
- 共三种接口，以形状、纹样和颜色共同区分。
- 不属于24张蓝图，不可制造、出售或带离地图，不占背包槽位。
- 用途在确认前显示；可以打开奖励区、恢复区或捷径。
- 主线必经通行方块独立保证，任何可选使用顺序都不得形成软锁。
- 任务权限门和谜题目标门不消耗通行方块。

## 7. 确定性接触战

### 7.1 属性与公式

双方共用四项属性：生命、攻击、防御、速度。

```text
单次伤害 = max(攻击方攻击 - 防守方防御, 0)
```

- 速度只决定第一次攻击者，不影响移动速度、攻击频率、行动次数或回合数。
- 速度较高者先手；速度相同则主动进入对方格的一方先手。
- 首击后双方一击一击交替，直到一方生命／耐久归零。
- 无暴击、闪避、随机浮动、元素克制、随机异常或动作指令。
- 玩家单次伤害为0时不能提交接触；界面不弹出笼统的“无法取胜”警告，而以0伤害预览和对已知路线／方块的可关闭温和引导帮助重新规划。

### 7.2 预览与表现

接触前必须显示：

- 主动方和首击者；
- 双方每次造成的伤害；
- 玩家需要攻击的次数和敌方获得攻击的次数；
- 特性带来的固定变化；
- 玩家预计损失与战后剩余生命。

确认后在原场景内用约1.5–3秒压缩演出完成结算；可以加速或瞬间跳过。展开记录可查看完整交替顺序，动画结果必须与预览完全一致。

阻拦解除不表现为击杀：地方生物离开，失控造物停机，异常聚合体稳定消散，古代执行体返回待机。没有血液、尸体、击杀数或从身体采集材料。

普通敌人无经验、无随机掉落。少量明确标为“载体”的对象可以放下战斗前已公开的地图专用物；这属于固定地图预算，不是刷取掉落。

### 7.3 数值与损耗验收合同

敌人档案以其首次出现章节的主线最低属性验证，不计算可选成长、商店或重复资源：

- 同一档案全局只用一组数值；基础档需玩家攻击2–5次，强化档3–6次，护盾最多额外增加1次攻击。
- 首次出现时玩家单击有效伤害至少为3；高速原型只需比同期最低主线速度高1，不用建立速度膨胀。
- 无特性必经普通敌人的预计损耗通常为最大生命的5%–15%，强化守卫为8%–20%。
- 计算护盾、满额支援或敌方先手后，单个普通敌人损耗仍不得超过25%；少量双特性敌人不得超过30%。
- 2–3名支援联动组必须存在一条公开击破顺序，使整组总损耗不超过35%。
- 损耗落在15%–25%的敌人只能作为公开的高成本守卫、捷径代价或可绕行威胁；双特性敌人不得位于唯一必经路线。

地图在最低合法入口状态下验证，只使用主线保证的属性、方块、材料与恢复：

| 路线内容 | 全图遭遇组 | 低损路线接触 | 直觉路线接触 |
|---|---:|---:|---:|
| 主线大型路线规划图 | 8–12，硬上限14 | 3–5 | 5–7 |
| 可选路线规划图 | 5–8 | 2–3 | 3–5 |
| 复合段／远征中的路线部分 | 4–7 | 2–3 | 3–5 |

- “遭遇组”是进入后必须连续作出同一组路线／支援判断、其间没有安全脱离点的一组敌人；“低损路线”是利用全部公开信息进行规划后的较低生命损耗解；“直觉路线”是首次游玩者按主目标、近路径和明显恢复点前进的可理解解。两类路线都必须作为固定测试夹具保存。
- 每图至少有两条只靠主线保证资源即可完成的路线；低损路线离场生命至少40%，直觉路线至少25%。
- 每张主线标准大型路线图至少有2个恢复点，短图至少1个；恢复点固定50生命，急救箱／应急站固定40生命。
- 合法路线至少交换生命、方块、消耗品、绕行距离、一次性节点或可选奖励中的两类代价，不允许存在所有维度都更优的唯一解。
- 可选成长和商店只能增加余量，不能成为主线完成条件；清空敌人不计奖励或完成度。
- 所有敌档、路线和恢复点进入中央测试数据；地图不得局部覆写阈值或公式。

## 8. 机关解谜区段

### 8.1 功能语法

所有谜题遵循“源头—传递—变换—目标”：

- 源头：按钮、压力板、能量源、水流起点、记录状态；
- 传递：导管、轨道、导流槽、移动平台、邻接连接；
- 变换：转向、分流、延时、反转、升降、同步或切换状态；
- 目标：门、稳定节点、升降机、同步装置或公共设施。

各地区改变外观、空间和组合重点，不改变基础语义。

### 8.2 房间规则

- 进入房间先观察公开目标、机关状态和固定配给。
- 每个有效操作推进一个谜题步；下一结果完整预览。
- 可以无限单步撤销和整室重置。
- 困住、坠落或机关失败只回到房间起点，不损失生命和全局材料。
- 必需方块全部由现场固定提供，不读取全局背包，也不出现无限库存。
- 房间只检查最终条件，不检查是否复现标准步骤；所有合法解均成功。
- 主线不评价最少步数，不因提示减少奖励。

主线地城通常5–8个主要房间，采用中央枢纽、2–3条可换序分支和最终综合房。房间状态局部保存，完成房间形成永久检查点，不要求跨房间搬运临时方块。

## 9. 实地探索区段

- 接受明确目标后移动、交谈、观察和调查；普通移动没有倒计时。
- 每段有少量必需事实，取得顺序自由；线索自动记录来源、地点和相关人物。
- 可选线索只补充人物、地区和历史，不影响固定结论，也不会永久错过。
- 必需事实齐全后，由固定人格的洛尔和阿莉娅自动整理结论。
- 若要求选择线索或回答问题，错误只产生解释并可重选，不改变剧情、关系或奖励。
- 不设置像素级寻找、无提示物品组合、随机遇敌或突然切换实时战斗。
- 叙事地图允许使用随身方块，但任务触发格、出入口和必要NPC通道为可见保护格。

## 10. 蓝图与方块

### 10.1 对象定义

- **蓝图**：永久制造知识，无数量、不占背包；记录功能、材料、放置、连接和生命周期。
- **成品方块**：制造出的实体，有数量和背包槽位，可部署或消耗。
- **现场配备**：任务／谜题临时提供，离开区段后归还，不进入全局库存。
- **固定设施**：环境实体，不进入背包；可以与便携方块拥有同类功能。
- **永久成长方块／恒久強化ブロック**：固定一次性内容奖励，接触后立即生效，不属于蓝图。

全部24张蓝图随固定主线解锁，不随机、不可遗漏、不设稀有度；首次解锁赠送1个对应成品。16张基础蓝图提供单一功能，8张高级蓝图组合或扩展已学规则，不必然替代基础版本。

### 10.3 来源与生命周期标签

来源：随身携入／持ち込み、现场配备／現地支給、固定设施／固定設備。\

普通合法格上的自有方块默认可回收。永久融合只有同时满足：兼容接合位、承担长期功能、任务含改造权限、玩家确认最终方案、不会封死必要路线。确认界面必须显示具体方块、不可回收事实和环境结果。

放入接合位但尚未提交时仍可回收；主动撤退会回滚融合。安全出口提交后，方块解除便携框架并成为环境的一部分，不表现为消失。

回收不得让角色失去合法落脚点或破坏仍存在的依赖。安全出口自动归还未融合自有方块、清理本地临时方块、提交融合和消耗，再发放奖励和保存。

## 14. 生产验证重点

以下项目必须在代表内容和完整九章生产中持续回归：

- 一步一格与长按移动是否清楚而不拖沓。
- 固定格网镜头对高差、悬台和遮挡的可读性。
- 确定性战斗在无随机、无装备下是否有足够路线决策密度。
- 24蓝图的依赖、回收、融合和自动归还是否可能软锁。
- 临时属性是否产生真正选择，而非固定最优。
- 有限槽位和整备频率是否形成规划而非整理负担。
- 机关多解、跨房间状态和三级提示的实现成本。
