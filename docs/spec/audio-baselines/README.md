# 游戏声音基准 v0.2

状态：**设计完成，暂定作为声音概念基准**。等待垂直切片、双平台技术输入与中日样带形成后统一复审；当前不代表最终曲目、演员、录音方式、混音数值或音频资产已经冻结。

详细规格：

- [音乐系统基准](music.md)
- [音效与环境声基准](sfx-and-ambience.md)
- [配音、本地化、混音与无障碍基准](voice-localization-accessibility.md)

## 1. 设计目标

- 建立童话、二次元、有趣、轻松、治愈的统一听觉身份。
- 让六个地区、三种行动区段、机构和古代设施可以辨认，但不割裂成不同作品。
- 让声音清楚辅助一步一格、方块改造、确定性比较和真实交通等规则。
- 支持简体中文（zh-CN）与日语（ja-JP）完整文本体系及对等配音覆盖。
- 长时间探索和思考不产生催促、惊吓或重复疲劳。
- 所有关键信息均有视觉、文字或数值冗余，听觉不是唯一通关条件。

## 2. 总体听觉身份

- 主体乐器：木管、原声拨弦、轻木质打击和弱音金属。
- 技术声色：柔和电子脉冲、玻璃泛音与实体机械卡榫。
- 世界动机：音级轮廓 `1—2—4—3`，对应一步、发现、停留和落格。
- 古代动机：世界动机逆行 `3—4—2—1`；最终真相处才与正向动机完整结合。
- 音乐采用“地区主题＋区段变奏”，不为三种行动区段建立互不相关的三套曲风。
- 危险通过和声、密度和旋律缺失表达，不切换成激烈动作战斗音乐。

## 3. 全局硬规则

- 敌人和重大阻拦禁止昆虫／节肢动物听觉语言，包括威胁性嗡鸣、振翅、口器摩擦、多足疾走和甲壳蜕裂。
- 自然昆虫仅可作为安全户外场景的低密度生态声，不能与敌人状态或隐藏目标绑定。
- 确定性接触结算禁止刀剑、枪炮、爆炸、受伤惨叫和死亡反馈。
- 生命耗尽表达为行动中止；敌人表达为收拢、停机、退让或解除阻塞。
- 系统不播放“无法取胜”警告，只对玩家当前可见、已发现或规则上已知的方块与路线提供可关闭的温和引导，不得泄露隐藏内容。
- 腐蚀使用滴蚀、剥落和材料磨损，不使用剧毒、骷髅、骨骼或恐怖心跳语义。
- 真实交通必须有连续物理声程，不使用传送升调、空间折叠或瞬间抵达声。
- 洛尔与阿莉娅固定为专业伙伴和挚友；音乐与配音均禁止恋爱编码。
- 希人不使用动物叫声、固定拟兽口癖或萌化音效代替人物塑造。
- 系统默认不人格化，不设置持续陪伴玩家的系统旁白。
- 未发现节点完全静音，不能通过音频泄露位置、类别或数量。
- 不设置惩罚性失败音乐；撤销、重做和重置保持中性。
- 一次事件只有一个承担主要语义的前景提示；音乐、UI确认号和功能音不得同时完整播报同一结果。

## 4. 内容规模

### 音乐

- 25个完整音乐身份。
- 37个主要可播放编配，其中包含六地区×三行动区段的18个地区编配。
- 3个短角色动机：洛尔、阿莉娅、伊尔玛。
- 10个可复用短音乐提示，不设置失败提示曲。
- 四个重大阻拦／终局音乐功能映射五个重大阻拦：三个实体型共享一个功能，两个情境型各用一个功能，第四个属于终局汇合。
- 独立音乐素材目标约100至120分钟；昼夜、天气与压力通过内部声部分层实现。

### 音效

- 24类方块各有一个身份短句和两个身份微变体，共享6类材质落座语法。
- 预览、有效、无效、危险、放置、融合、回收、永久融入和升级各有统一状态语法。
- 生命、攻击、防御、速度分别拥有永久、临时和结束反馈。
- 12敌人族各有一个身份短句；强化态叠加结构层，不建立新身份。
- 五个重大阻拦各有一个环境签名及静止、运作、解除三套状态。
- 九组脚步表面、高频UI 6至8个变体、一般机关与工具3至4个变体。

### 配音

- A级：主线、序章／结局、章节演出、关键揭示、重大阻拦和强制教学完整配音。
- B级：为主线服务的支线、命名角色支线和专门演出完整配音。
- C级：普通支线、重复交互和次要NPC采用节点式配音，正文保留完整双语文本。
- D级：菜单、图鉴、物品、地图和一般状态不使用角色配音，以功能音和可选朗读表达。
- 简中与日语覆盖级别完全相同，文本和配音语言可独立切换。

## 5. 系统关系与混音优先级

```text
剧情／玩法／地区／昼夜天气状态
        ├── 音乐声部分层
        ├── 环境声床与近景事件
        ├── 方块／机关／UI功能音
        └── 角色与设备语音触发
                       ↓
             信息优先级与动态避让
                       ↓
无障碍朗读（启用时） > 配音 > 关键玩法反馈 > 辅助导航 > 世界交互 > 环境声 > 音乐装饰层
                       ↓
       立体声／单声道／声音字幕／辅助提示
```

状态只从游戏规则向各声音层单向分发，音乐、音效和配音之间不互相改写玩法状态，避免反馈循环。

## 6. 核心选择与被否决方向

- 采用共享四音动机和地区变奏；否决为每个模式和地区建立完全独立曲风。
- 采用“材质＋功能＋状态”的组合音效；否决给每个方块制作互不相关的一整套声音。
- 采用确定性比较与结算后生命反馈；否决动作攻击、随机暴击和击杀音效。
- 采用分级双语配音；否决所有文本一律配音造成的普通交互冗长，也否决主线外完全无声。
- 采用信息冗余与可配置辅助声音；否决必须听音才能完成的谜题。

本方案假设三种行动区段可能在同一地区内频繁切换。即使最终技术结构将它们放入独立场景，三套编配仍共享调性、速度、乐句长度与地区动机，因此无需推翻音乐身份。

## 7. 联合复审门槛

剧情、视觉和技术框架完成后集中复审：

- 六地区盲听可辨，但没有风格拼贴。
- 三种行动区段切换清楚而连续，资源紧张形成思考压力而非动作压力。
- 古代逆行动机不会在最终真相前泄露答案。
- 洛尔、阿莉娅和伊尔玛的音乐与声线符合人物关系、年龄和职责。
- 方块音与视觉状态、结算数字及实际规则完全同步。
- 真实交通、地图隐藏信息、无昆虫敌人和非死亡语义均未被声音破坏。
- 中日文本、字幕、语音覆盖、术语和情绪终点一致。
- 30分钟、60分钟及完整章节体验没有明显重复疲劳和对白遮蔽。
- 笔记本扬声器、普通耳机、单声道和夜间动态范围均能完成三种行动区段。

## 8. 当前明确不冻结

- 正式曲名、主题歌、商用原声专辑规划。
- 最终演员、录音棚、真人／合成／混合制作方式。
- 任何可识别演员或名人的声音模仿。
- 文件格式、采样率、声道、流式加载、压缩和口型同步方案。当前技术基线已固定使用 Godot 内置音频系统，不再把外部音频中间件列为待选项。
- 平台响度、最终总线数值和各场景自动避让的最终参数。

这些项目分别在剧情定稿、双平台生产样本或正式采购前由对应负责人处理，并在不可逆外部支出前交由用户确认。
