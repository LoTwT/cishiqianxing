# 配音、本地化、混音与无障碍基准

状态：**设计完成，等待中日声线样带与视听联合复审**。本文件锁定覆盖规则、表演边界和验收标准，不锁定最终演员、录音棚、真人／合成／混合制作方式或技术规格。

## 1. 语言与配音覆盖

游戏仅提供简体中文（zh-CN）与日语（ja-JP）两套正式文本、字幕和配音。文本语言与配音语言可独立选择，允许“简体中文文本＋日语配音”或“日语文本＋中文配音”；字幕跟随文本语言。切换语言不影响存档和剧情状态。

简体中文稿是事实、设定与剧情意图的语义母稿；日文稿按相同人物关系、信息量和情绪功能自然改写，不逐字硬译。两种语言的配音覆盖级别必须一致，不能让某一语言独占完整配音，也不能用另一语言填补缺失。

| 级别 | 内容范围 | 规则 |
|---|---|---|
| A：完整剧情配音 | 主线、序章与结局、章节开闭幕、关键揭示、重大阻拦演出、强制教学 | 场景内全部对白均有中日双语配音 |
| B：完整角色配音 | 为主线服务的支线、命名角色支线、有独立镜头或专门演出的场景 | 场景内全部对白均有中日双语配音 |
| C：节点式配音 | 普通支线中间步骤、重复交互、次要NPC与环境交流 | 进入、关键变化和结束节点使用短句或反应音；正文完整显示双语文本 |
| D：非角色语音 | 菜单、图鉴、物品、地图、数值与一般方块状态 | 不配置角色配音，以功能音效、字幕和可选朗读表达 |

玩家选项若存在，只改变当下措辞或一句短反应，不改变事实、关系、主角性格和结果；选项后返回固定正典台词。配音不得暗示不存在的剧情分支或感情路线。

## 2. 七名角色的声线边界

| 角色 | 表演方向 | 必须避免 |
|---|---|---|
| 洛尔 | 青年男性自然中声区，明朗但不浮躁；好奇、善意、行动力明确，幽默克制；压力下提高专注度 | 空白玩家化、持续少年英雄式喊叫、强硬领袖腔、故作深沉；对阿莉娅暧昧低语 |
| 阿莉娅 | 成年女性清晰中声区，反应快、吐字利落，专业与轻松机敏并存；建立信任后有自然玩笑 | 萌系动物拟声、狐媚诱惑、过度冷酷、撒娇代替判断；调情、嫉妒或情侣式反应 |
| 伊尔玛 | 52岁女性成熟中低声区，温暖、稳定、有生活感；失传技术与历史来自长期研究，能区分已知、推测与未知 | 老妪化、虚弱沙哑、全知导师腔、连续说明式平读、把学识演成玄学预言 |
| 罗兰 | 成年男性稳健中低声区，停顿从容，情绪克制但关切可辨 | 未经剧情支持的指挥官或上级腔、吼叫、兽吼和粗暴威压 |
| 卡洛 | 青年男性明快中声区，反应灵活，外显度高于洛尔；严肃场景自然收束 | 儿童化、持续吵闹热血、固定搞笑担当、所有场景同一兴奋度 |
| 芙兰 | 成年女性饱满温和的中低声区，节奏舒展、有耐心，坚持立场时清楚有分量 | 因熊类希人而迟钝、笨重、母性模板化、低吼或喜剧化粗声 |
| 尤恩 | 青年男性干净柔和的中声区，措辞和停顿带思考感；比洛尔更内敛，先整理信息再表达 | 胆怯结巴、冷漠精英腔、与洛尔使用相同节奏和情绪曲线 |

希人特征通过习惯、反应速度和人物个性体现，不以动物叫声、固定口癖或夸张喘息代替塑造。动作发声短促、功能明确且非色情化。洛尔与阿莉娅固定为专业伙伴与挚友：允许关心、拌嘴和默契，不出现调情、占有欲、羞涩恋爱反应或情侣式收束。

## 3. 录制与资产规则

每条语音以语言无关的事件ID为核心：

`VO_{内容类型}_{章节或地区}_{场景}_{角色}_{序号}_{变体}`

正式文件增加语言后缀，例如：

- `VO_MS_C02_S014_LOER_003_zh-CN`
- `VO_MS_C02_S014_LOER_003_ja-JP`

- 原始录音另加批次和take编号，正式资产不保留take编号。
- 一个文件只包含一个可独立触发的事件；动作音、呼吸、打断词和完整台词分别记录。
- 台词清单记录说话对象、上下句、场景目的、人物掌握的信息、身体动作、情绪强度、打断与停顿。
- 所有角色名、地区名、机构名、方块名和“希人”等设定词维护中日双语发音表；中文记录拼音声调，日语记录已确认假名读法和重音参考。
- 两种语言不追求音色复制，但年龄感、外放程度、温度、节奏倾向、人物关系和情绪终点必须一致。
- 事实或人物意图修改时先更新语义母稿，再同步两种文本、字幕和语音清单。
- 镜头按语义拍点设计，不被单一语言句长锁死；开闭口、重音动作、打断点和镜头结束分别适配当前语音。
- 每次修订建立新版本与变更记录，不覆盖来源不明的旧文件。

## 4. NPC、环境人声和系统语音

- 反复登场的命名NPC具有可辨认声线；同一演员可复用次要角色，但相邻剧情段不能出现明显重复声线。
- 地区差异通过用词节奏、交流距离和人声密度建立，不使用现实地域口音或方言刻板印象。
- 环境人声使用低语义密度双语素材，避免背景反复播放完整句子，也不能提前泄露隐藏目标或剧情事实。
- 系统默认不人格化，不设置持续陪伴的“系统旁白”；确认、无效、危险和模式切换使用功能音效。
- 剧情中会发声的设备按角色语音管理；无障碍朗读属于功能层，不产生新的剧情人格。

## 5. 字幕与声音字幕

- 所有角色语音均有完整字幕；有玩法意义的非语音声提供可选声音字幕。
- 声音字幕只描述玩家当前能够感知的信息，不泄露隐藏物体和未揭示事件。
- 支持字号、行距、背景透明度和高对比调整。
- 始终显示玩家当前已知的说话者标识，并用文字或图标辅助区分，不只依赖颜色；身份尚未揭示时使用本地化的“陌生声音”“未知设备”等中性标签，揭示后才显示姓名。声音字幕的来源字段遵守同一知识状态。
- 支持自动播放速度调整、关闭自动播放、对话历史和最近语音重播。
- 同时说话时分轨显示，保持说话者对应。
- 中日文分别自然断行；文本语言和语音语言独立切换。
- 剧情信息不得只存在于声音；关键方向、状态、机关结果与危险同时提供视觉反馈。
- 关键可交互状态也应有功能音或可选朗读，不要求玩家只靠颜色、细微音高或立体声方向完成流程。

## 6. 混音与长时间舒适度

玩家可独立调整八组音量：总音量、音乐、角色语音、环境声、世界交互与方块音效、界面与功能提示、辅助导航、无障碍朗读。关闭辅助导航不会关闭屏幕朗读。无障碍朗读设置同时驱动游戏内 Narration 总线和系统 TTS 的逐句音量参数；系统屏幕阅读器自身音量仍由操作系统管理。

- 默认动态范围为“标准”，另提供“宽动态”和“夜间”。
- 语音出现时音乐和环境温和避让，不突然消失；提供额外“对白清晰度增强”。
- 无障碍朗读启用并触发时拥有最高信息优先级：非紧急提示延后，角色语音在可安全暂停的界面中等待朗读结束；剧情演出中则先完成角色语音，再朗读新获得的界面信息，二者不得相互覆盖。
- 高频重复行为使用自然变体并保留识别核心；一步一格、光标、拾取、放置和无效操作不得形成尖锐密集压力。
- 连续重复时非紧急声音可自动降低存在感，关键含义不得丢失。
- 深脊和重大阻拦通过节奏、和声与空间形成压力，不依赖巨响、持续低频或恐怖音效。
- 完整章节与三种行动区段连续体验中不得出现明显耳疲劳、短循环暴露或对白长期被遮盖。

## 7. 无障碍音频设置

- 完整字幕与声音字幕。
- 单声道混合、对白清晰度增强、夜间动态范围和降低突发声音。
- 降低重复提示音；角色闲聊与重复动作语音频率可设为正常、较少或关闭。
- 重要声音提供方向文字或屏幕边缘提示。
- 网格焦点、可交互物、物理／规则上不可通行的路径和机关结果提供可选辅助音；路径提示不能表示“无法取胜”，也不能评价一条规则上可行路线的优劣。
- 菜单与关键状态提供可选朗读；所有辅助音可预览并单独调节。
- 设置在重启、切换语言和读取存档后保持有效。
- 辅助提示不只靠左右声道或音高区分，至少再配合节奏、音色、文字或图形之一。
- 关闭重复角色语音不得关闭主线台词和关键教学信息。

## 8. 生产验收

- A、B级语音逐事件核对，中日两种语言覆盖完全相同，无错语言和临时占位。
- 七名角色均以日常、轻松、压力、知识说明和同伴交流场景检查声线边界。
- 洛尔与阿莉娅全部共同场景单独审查，不出现恋爱化演绎。
- 中文与日文分别由母语审校进行文本、语音、字幕和实机场景联检。
- 专有名词读音与双语术语表一致。
- 无爆音、削波、明显底噪、剪辑点击、空间跳变和错误截尾。
- 使用普通耳机、桌面扬声器及笔记本扬声器验证对白可懂度与提示辨识度。
- 三种行动区段切换时音乐自然衔接，功能音含义不漂移。
- 所有关键声音均有视觉替代，所有关键视觉状态均有辅助音或朗读路径。
- 完整章节连续体验后，无显著重复疲劳、惊吓式音量跳变或持续遮蔽对白。

## 9. 联合复审与暂缓项

下列事项有明确后续阶段，不属于当前遗漏：

- 角色造型和剧情场景完成后，由角色与叙事设计联合复审声线及表情动作。
- 剧情节奏完成后，由叙事设计复审A／B／C级分布和对白密度。
- 正式音乐、环境声与界面形成后，由声音与UI设计复审语音避让、功能映射和声音字幕。
- 当前技术基线使用 Godot 内置音频系统承载八组总线、动态音乐、流送与跨场景连续性；通过双平台生产样本后，再由技术与声音实现共同确定文件格式、采样规格、声道、响度、压缩、流式加载和口型同步。
- 正式制作前，由用户集中确认中日两套最终演员声线及真人、合成或混合制作方式；不得模仿名人或可识别演员。
- 录音棚、演员与供应商只在正式采购前选择；版权、授权范围、声音再利用和模型训练权限必须写入可验证条款。
