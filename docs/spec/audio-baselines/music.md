# 音乐系统基准

状态：**设计完成，等待垂直切片与视听联合复审**。本文件锁定音乐职责、声色、结构和内容预算，不锁定最终作曲者、录音阵容、音频中间件或发行曲名。

## 1. 音乐职责与硬规则

音乐负责统一方块世界、童话气质与古代技术感，帮助玩家辨认地区、行动区段和剧情状态，并调节探索、思考与规划的节奏。音乐不把敌人出现包装成传统“开战”，也不替固定剧情强迫情绪。

- 木管、原声拨弦、轻型木质及弱音金属打击构成主体；柔和电子音只用于方块机关、异常现象和古代技术。
- 六个地区、主要机构和古代设施必须属于同一个音乐世界，不拼贴彼此无关的曲风。
- 地区主题是主体，三种玩法使用同一主题的不同编配。
- 危险通过和声悬置、低音脉冲、声部密度与旋律残缺表达，不依赖突然增大音量、加速、重鼓或动作音乐。
- 深脊不能听成恐怖地区，环庭不能听成反派帝国，炉歌不能听成嘈杂工厂，余响不能听成死寂废墟。
- 谜题音乐不提供倒计时压力；长时间思考时主动减少声部。
- 失败、撤销和重置不使用惩罚性号角，只短暂抽走声部并自然返回当前状态。
- 洛尔与阿莉娅的共同音乐采用问答、接力或交错声部，不采用恋爱式弦乐二重奏和贴近型双旋律。
- 游戏内音乐不使用有语义的歌词；允许极少量无词哼唱或气声，确保中日版本音乐内容一致。
- 音乐必须为配音、环境声和关键交互音留出空间；安静与仅保留环境声是正式设计状态。

## 2. 世界四音动机

核心音级轮廓为：

`1—2—4—3`

节奏为“两枚轻短音起步，第三音延展，第四音温和落定”，对应迈出一步、发现变化、稍作停留和落在下一格。

- 普通探索中，完整动机最多每32小节突出一次；其余时间只使用局部音、节奏轮廓或和声暗示。
- 六地区改变音阶、配器、速度和重音，但保留轮廓。
- 古代设施主要使用逆行形态 `3—4—2—1`；真相揭示前正向与逆行只不完整重合，最终真相处才首次同时完整成立。
- “小型发现两音、重要发现三音、主线关键真相四音”只约束发现提示的三级语法；正向四音此前可以作为背景主题、角色陈述、谜题补全或阻拦解决句出现。最终真相的唯一标志是正向与逆行首次同时完整成立。
- 解谜成功优先由玩家连续操作自然补全动机，不额外播放夸张胜利旋律。
- 失败不通过失真、走音或破坏世界动机表达。

角色对动机的使用：

- 洛尔：温暖拨弦或木管低音区完整陈述正向动机，强调稳定与亲自行动。
- 阿莉娅：从末音出发，以轻木管回应，强调观察、调查和敏捷判断。
- 伊尔玛：前三音延长，第四音在停顿后出现，表现成熟学者、历史经验和未说尽的信息。
- 其他配角归属地区或机构音乐，不额外建立完整角色主题。

## 3. 六地区声色

| 地区 | 核心声色 | 旋律与节奏 | 禁止偏移 |
|---|---|---|---|
| 晴野 | 木笛、尼龙弦、中提琴拨奏、软沙锤 | 明亮五声性、开放和弦、舒展的4/4与轻6/8 | 幼儿化、乡村舞曲化 |
| 潮织 | 竖琴、马林巴、柔和手风琴、玻璃小打击 | 6/8与3/4交替，悬挂和声与水流式琶音 | 密集水滴、失去节奏的空泛梦幻 |
| 炉歌 | 扬琴、低音拨弦、木块、弱音金属、巴松 | 有秩序的交错节奏，表现多人协作 | 工业轰鸣、铁锤重拍、机械压迫 |
| 深脊 | 低音单簧管、大提琴拨奏、石质敲击、刷奏框鼓 | 慢速开放五度、短句回声，高音保留方向与生机 | 恐怖持续低音、地下怪物、黑暗宗教 |
| 余响 | 中音长笛、木质共鸣、远钟、柔和颤音琴、轻电子延迟 | 旋律延迟回应自身，空间感明显但保持温度 | 鬼魂哀鸣、死亡空间、过量混响 |
| 环庭 | 双簧管、单簧管、室内弦乐拨奏、键拨、木块 | 对称乐句、规律分句、克制复调和少量生活化切分 | 军乐、反派进行曲、冷酷宫廷感 |

## 4. 三机构声色

### 一格工坊

- 尼龙弦、巴松、马林巴、木块和弱音小金属。
- 节奏像工具依次接手工作，轻巧、有秩序，但不复制真实敲打声。
- 忙碌时增加中层节奏，交流时只保留拨弦与木管。
- 世界动机以最直接、最亲切的形式出现。

### 六方院

- 室内弦乐、双簧管、单簧管、竖琴和轻键拨。
- 采用六拍分组和温和复调，体现理性、历史和文明积累。
- 不使用宏大铜管或威权进行曲；不同部门只改变主奏乐器，不另写部门主题。

### 古代设施

- 玻璃泛音、钢片琴、弓擦金属、柔和正弦脉冲、气声与低量木管。
- 拍点较模糊，但仍可感到方格式周期。
- 使用世界动机的逆行、延长与错位形态。
- 电子声可与原声平分权重，但不得变成外星、赛博霓虹、太空科幻或恐怖遗迹。

## 5. 三种玩法的音乐结构

每个地区主题提供六类可组合功能层：调性底层、地区主旋律、行动节奏、思考层、异常／古代层、压力层。

### 实地探索

- 使用最完整旋律和最宽空间感；行走不逐格触发音乐音符。
- 接近兴趣点时先加入地区副乐器，再出现短动机，不直接播放奖励号角。
- 对话时降低主旋律密度，保留地区和声与空间层。

### 路线规划

- 保留地区和声与主题轮廓，增加轻打击、拨弦低音和规则脉冲。
- 资源趋紧时抽走高音与装饰声部并加入低位短脉冲，不播放警报。
- 有效规划完成后让节奏与旋律自然咬合一轮，不播放动作式胜利音乐。

### 机关解谜

- 主旋律缩减为两音或三音碎片，使用木、玻璃与轻拨弦提供稀疏时间参照。
- 方块交互音位于当前音乐音阶内，正确连锁逐步补全乐句。
- 长时间无操作时逐层变薄，最终只留和声底层与环境声。
- 撤销、重做和重置保持中性。

## 6. 昼夜、天气和剧情优先级

- 白昼：主奏清晰，高音泛音与轻打击较完整。
- 黎明／黄昏：减少节奏，增加持续内声部。
- 夜晚：降低主奏音区，弱化高频打击并增加柔和延音；不能把所有地区简单改成小调。
- 昼夜变化用20至60秒逐层完成，不重启曲目。
- 风／雾延长尾音并减少短打击；雨／雪软化起音；强天气增加低层脉冲和悬挂和声，但不突然提速。

音乐内部状态优先级：

1. 主线关键揭示或章节结局
2. 重大阻拦
3. 当前行动区段
4. 调查、异常、慰藉等剧情状态
5. 天气与昼夜
6. 地区基础主题

这一顺序只决定冲突时哪个音乐层位于前景，不自动清除较低层。剧情对话锁定玩家操作时，玩法节奏层暂停，由叙事层接管。日常交流保留地区音乐；调查增加两音线索动机；异常减少稳定终止式；真相揭示才完整结合正向与逆行动机。事件结束后先保留3至6秒环境声，再让地区主题返回。

## 7. 重大阻拦与主线节点

重大阻拦统一使用四段音乐结构：

1. 观察：抽薄地区主题，但保留地区音色。
2. 介入：加入低层周期和残缺动机。
3. 推进：随有效行动逐步恢复旋律结构，不持续抬升音量。
4. 解决：正向世界动机可以完整出现一次，短暂安静后回到地区音乐；除非该事件同时承担最终真相揭示，否则不得与完整逆行动机重合。

三个实体型重大阻拦以节奏、材料声色和密度表达质量；两个情境型重大阻拦以和声悬置、空间与旋律缺失表达局面失序。两者均不使用Boss号角或动作战斗曲。

- 章节开场：8至16秒地区主题预示。
- 中段发现：不换曲，只让世界动机多完成一个音。
- 章节高潮：扩展地区编配并加入相关人物动机。
- 章节收束：恢复完整地区主题，突出道路恢复和居民重新生活。
- 最终真相：正向与逆行四音动机首次同时完整成立。
- 最终结局：以各地区与角色声色共同加入表现重新连接，不靠更大音量表现结束。

## 8. 音乐内容预算

### 25个完整音乐身份

- 全局与流程6个：世界主题、主菜单、旅途／交通、休息与安全、章节收束、结局与制作人员。
- 地区主题6个：晴野、潮织、炉歌、深脊、余响、环庭。
- 机构主题3个：一格工坊、六方院、古代设施。
- 叙事主题6个：日常同行、调查线索、异常疑问、安静慰藉、失传技术显现、真相与共同修复。
- 重大阻拦／终局功能4个：实体阻拦、机关失序、环境困局、终局汇合。

### 主要可播放编配

- 六地区各有实地探索、路线规划、机关解谜三种编配，共18个地区编配。
- 加上全局6、机构3、叙事6、重大阻拦／终局功能4，共37个主要编配。
- 昼夜、天气、压力和古代状态是编配内分层，不扩张成独立曲目。
- 洛尔、阿莉娅与伊尔玛各有一个短角色动机，不另建独立角色曲。
- 设置10个短音乐提示：三级发现、两级谜题完成、路线恢复、目标更新、重大阻拦出现、重大阻拦解决、章节转场。
- 不设置失败提示曲。
- 独立音乐素材总量目标为100至120分钟，通过分层、轮换与留白支撑完整流程。

五个重大阻拦与四个音乐功能的映射固定如下：三个实体型阻拦共享“实体阻拦”，以地区配器和各自环境签名区分；两个情境型阻拦分别使用“机关失序”和“环境困局”；“终局汇合”属于最终主线音乐，不代表第六个重大阻拦。最终事件若包含既有阻拦，只叠加对应环境签名。因此始终保持25个音乐身份、37个主要编配和五套独立阻拦环境签名。

### 单一前景提示规则

- 一次事件只能有一个承担主要语义的前景提示。
- 节点功能音说明节点类型；音乐只在重要发现时说明剧情等级。
- 路线恢复先播放设施真实开启声，音乐提示到下一乐句才进入。
- 重大阻拦环境签名负责辨认来源，音乐负责剧情压力，两者错开起音。
- 谜题完成使用音乐提示时，通用确认音只保留极短物理反馈。
- 同一事件不得同时叠加完整音乐号、UI确认号和功能音短句。

## 9. 切换与疲劳控制

- 同地区三种行动区段共享调性中心、基础速度和乐句长度，通常在乐句末用1至2小节增减声部。
- 跨地区使用4至8小节桥段：旧节奏退出，新地区主奏预示，再替换和声底层。
- 局内菜单保留当前位置调性底层并移除主旋律与节奏；标题主菜单使用独立音乐。
- 对话只降低密度，不随每句台词切歌；谜题重置保持当前循环进度。
- 探索编配单次循环不少于3分30秒；规划与谜题不少于2分30秒。
- 每地区至少两套主奏轮换，每个长循环包含8至16小节低密度区。
- 高频木琴、玻璃音和金属打击不得持续承担拍点。
- 返回刚离开的地区时从不同乐段或弱主奏状态恢复。
- 用30分钟、60分钟和跨地区连续游玩三种时长进行疲劳验收。

## 10. 联合复审标准

- 盲听时六地区可以区分，但仍属于同一作品。
- 三种玩法清楚可辨且不割裂；资源紧张产生思考压力而非动作压力。
- 世界动机可被记住但不频繁；古代逆行动机不提前泄露最终真相。
- 洛尔与阿莉娅的共同音乐不带恋爱暗示；伊尔玛不像神秘预言者。
- 音乐不遮挡配音、环境声和关键方块反馈。
- 章节结束强调道路恢复和日常生活，而非击败Boss。
- 视觉联合复审时，地区材质、光照温度与音乐声色必须作为一组判断。
