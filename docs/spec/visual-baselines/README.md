## 全局硬规则

- 正常二次元人物比例；柔和倒角的立体方格世界；温暖手绘材质。
- 世界方格是自然法则，不表现成数字模拟、CRT或赛博空间。
- 敌人与重大阻拦禁止昆虫与广义节肢动物语言，包括触角、复眼、口器、昆虫翅、多足、分节甲壳、幼虫、茧、蜂巢、蛛形、蝎形和甲壳类轮廓。
- 战斗呈现为确定性接触结算，不使用动作战斗、血腥击杀、QTE或隐藏阶段。
- 交通节点必须表现为真实交通网络，不使用任意传送门。
- 地图只显示已经发现或已知但未解锁的内容；尚未发现的节点不泄露位置、类别、槽位或总数。
- 谜题模式只使用关卡现场固定配给或固定设施，不出现无限库存。
- 洛尔与阿莉娅是专业伙伴与挚友，不设置恋爱线，也不采用情侣式收束构图。
- 正式界面文本仅提供中文与日文；概念图中的数字只用于显示信息层级。
- 不设置永久小地图、角色好感界面、分支选项、抽卡或稀有度视觉。

## 稳定提示集

以下为后续重绘与变体生成时使用的稳定提示摘要，而非一次性自由发挥：

1. **总风格**：原创3D二次元游戏；正常人物比例；柔和倒角方格；手绘木材、陶瓷、金属和织物；明亮治愈；避免像素体素、赛博朋克与现有游戏复刻。
2. **角色**：从角色圣经锁定年龄、种族、职责和性格；以既有角色板做身份参考；无武器、性感化、抽卡立绘姿态和视图间换装。
3. **地区**：同一世界结构语法，不同地区通过地貌、公共设施、主材质和主色区分；人物只作比例参考。
4. **方块与工具**：所有物件必须在游戏镜头下读得清；功能由轮廓、端口、运动方向和材质表达，不依赖文字。
5. **敌人与重大阻拦**：固定族名和行为职责；基础与强化态保持同族轮廓；严格执行无昆虫、无节肢动物、无血腥规则。
6. **UI**：世界画面优先；奶油白、深青、琥珀为主；危险珊瑚、保护蓝；确认前显示确定性结果；避免移动端堆叠和CRT电视外框。
7. **特效**：青绿表示有效与回收，琥珀表示激活与时序，蓝表示保护与锚定，珊瑚表示危险与无效，紫色仅用于更新或回收过渡；颜色必须配合形状和运动。
8. **插画**：环境与角色同等重要；安静的阶段收束，不使用胜利姿势、浪漫暗示、剧透意象或抽卡式构图。

## 已知制作期修正

- 阿莉娅包带与五金在三视图间需统一。
- F01绒角兽在`11`号概念板中缺少与正式名称对应的角；正式制作必须补上圆钝、绒质的小角，该板对F01只保留配色与材质参考。
- 罗兰短后掠角的长度和弧度需制作稿锁定。
- 尤恩与洛尔远景同为黑发男性，需通过发型、外套色块和站姿继续拉开。
- 深脊可在实际关卡中略微提亮，保证轻松基调与格线可读性。
- 晴野／余响及潮织／环庭在制作期需继续依靠材质、地标轮廓和公共设施拉开，不只依赖色相。
- 余响和古代设施正式贴图不得保留生成式伪文字；古代室内应沿用象牙、浅青与暖琥珀语言，避免地下城化。
- 方块工具、共鸣校准器等工具的手持比例需在角色模型旁再次校准。
- `16`号概念板需按已接受的轴对齐、足球直播感低俯角正交镜头重画；重画前只使用其环境与HUD参考。
- 实地探索区段需处理跟随角色的视野遮挡，并保证近处格线与交互物始终可读。
- 有效／无效放置及各类属性状态不能只依赖颜色；正式制作需加入形状、纹理、动画与音效差异，并提供减闪、减粒子选项。
- 雨夜和古代室内需设置格线、交互轮廓及状态色的最低对比度阈值。
- 正式 UI 阶段需验证日文长句换行、姓名宽度和中日文字体授权。
- 概念板不锁定模型面数、UV、贴图尺寸、骨骼、动画帧数、字体文件或最终UI像素位置。

## 不在本批次

- Logo、字标和商店主视觉；正式中日标题已经确认。
- 每名角色的最终建模拓扑、表情形变和服装拆件。
- 逐地区完整建筑套件、每个关卡的最终灯光烘焙与全部剧情插画。
- 正式中文／日文字体授权和逐界面排版；这些需要在技术与发布条件明确后冻结。
