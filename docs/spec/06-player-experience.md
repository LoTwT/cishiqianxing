# 06｜玩家体验

## 1. 第一小时

开场不是独立教学关，而是晴野“一格工坊的普通上午维修清单”。

| 时间 | 场景 | 教学内容 |
|---:|---|---|
| 0–6分钟 | 工坊起居区 | 一格移动、镜头旋转与回正 |
| 6–12分钟 | 工坊外街道 | 交互、查看环境与任务信息 |
| 12–20分钟 | 社区送货台 | 基座的预览、放置、回收和确认后环境融合 |
| 20–27分钟 | 旧仓侧巷 | 首次确定性接触战与完整预览 |
| 27–33分钟 | 街角校准点 | 现场配备的临时攻击强化如何改变战果；不用也能通过，不提前解锁“攻势”蓝图 |
| 33–41分钟 | 公共排水设施 | 结构抵达高处、现场导管、固定开关与单线信号 |
| 41–50分钟 | 返回工坊 | 蓝图、工作台、三种材料和首次固定制作 |
| 50–54分钟 | 工坊安全区 | 自动检查点和手动存档入口 |
| 54–60分钟 | 工坊外广场 | 无人路缘安静错开一格；伊尔玛疏散居民，阿莉娅抵达并开始调查 |

第一小时不开放完整仓储管理、复杂规划、永久成长、多房间机关、角色切换、工坊升级和重大阻拦。

首次战斗使用固定教学数据：洛尔为`100／10／5／10`，对手为`18／7／2／8`。洛尔先手、单击8、攻击3次、承受2次×2点伤害，预计损失4；使用现场临时攻击＋2后单击10、攻击2次、只承受1次2点伤害。该强化是教学现场配备，不进入背包；可制造的“攻势”蓝图仍在第4章解锁。

## 2. HUD信息架构

采用统一骨架，三个区段只展开相关信息：

- 左上：当前目标摘要。
- 左下：角色、生命与临时效果；路线区段展开攻击、防御、速度。
- 下方中央：方块与工具栏，不使用时收起。
- 右下：当前2–4个可执行动作；机关区段增加撤销、重置和提示。
- 世界画面：交互标记、格子光标、作用范围、路线与结果预览、非法原因。

路线规划必须直接显示战斗先手、单击伤害、攻击次数、预计损失、战后生命和路线累计损耗。机关解谜隐藏无关战斗数值，显示固定配给、目标状态、信号和下一变化。实地探索只保留目标、字幕和当前交互，接近可改造区域时才展开方块栏。

非法放置必须显示具体原因，如缺少支撑、格被占、受保护、接口不兼容或回收会破坏依赖。任何危险和有效性至少使用颜色、形状／纹理、图标、数字或文字中的两种。

## 3. 菜单与信息归属

暂停入口：继续游戏、冒险信息、保存／读取、设置、返回标题／退出。

“冒险信息”四页：

- 状态与行装：洛尔属性、临时效果、携带方块、工具、材料、任务物品和背包槽位。
- 任务：进行中／已完成；可筛选；同时追踪一个任务。
- 地图：世界、地区、现场三级地图。
- 记录：已学规则、蓝图、机关、敌人、人物、地区、章节摘要及重要已完成对话。

任务回答“做什么”，地图回答“在哪里”，状态回答“带着什么”，记录回答“知道什么”。制作、仓库、拆解和工坊升级使用独立全屏工坊界面。

新内容只用小型“新”标记；选中后清除，可一键标为已读或关闭。没有促活红点、限时提醒或通知中心。

## 4. 地图与知识状态

### 4.1 三级地图

- 世界地图：六地区、一格工坊、真实交通关系、任务与已启用交通节点。
- 地区地图：已发现街区、地标、安全点、任务范围、永久捷径和任务入口。
- 现场战术地图：当前格网、高差、楼层、敌人、机关、方块和资源状态。

默认不设置永久小地图。若实机测试显示叙事区域频繁迷路，只能增加可关闭的小型方向辅助，不能泄露未知内容。

### 4.2 未知、已知和发现

- 未发现内容不显示位置、类别、空槽或总数，也不通过声音泄露。
- 已知但未开放的节点可显示名称范围和锁定状态。
- 取得地址后才显示入口；亲眼确认目标后才精确到格。
- 路线规划入场公开所有与规划有关的公共信息；隐藏秘密仍不公开。
- 机关地图只记录已观察房间和当前／下一状态，不显示隐藏线路、正确顺序或多步答案。
- 观测点只补充附近已知路线、规则和阻拦准备，不揭露秘密位置或谜底。

地图打开时暂停世界，不消耗步数。

## 5. 世界节点

| 节点 | 日文 | 职责 |
|---|---|---|
| 安全点 | セーフポイント | 保存、基础整备、失败安全返回；默认不治疗 |
| 恢复点 | 回復ポイント | 一次恢复固定50生命；使用后永久标记已用 |
| 交通节点 | 交通拠点 | 加入真实公共交通网络；首次亲自抵达／修复后开放 |
| 观测点 | 観測地点 | 补充附近已知路线、规则和重大阻拦准备信息 |
| 固定终端 | 固定端末 | 推进机关、任务或地区状态；执行前预览影响 |
| 区域出入口 | エリア出入口 | 切换地区／任务现场；本身不自动保存、治疗或传送 |
| 系统检查点 | チェックポイント | 自动快照逻辑，不是世界中的可交互实体 |

同一地点可以具有多个功能，但必须使用独立图标和说明。

## 6. 真实交通

- 每区固定一个聚落交通节点；只有明确回访需求时增加一个外部节点，完整世界最多12个公共节点。
- 节点首次必须亲自抵达并修复；之后永久开放。
- 已开放节点间免费旅行，不扣方币、不触发随机遭遇，也不能进入任务深处或逃离未结算外出段。
- 表现为轨道、渡运、公共车辆等真实交通，包含上车、连续行驶、减速和到站；不使用传送门、空间折叠或瞬间消失。
- 首次旅程展示完整地域连接；后续旅程允许在不破坏实体交通语义的前提下加速或跳过中段，具体时长由原型测试冻结。

## 7. 键盘与鼠标

操作语法统一为“移动—指向—确认—取消／撤销”。

- WASD与方向键均可移动；默认严格为 `W=屏幕上、A=屏幕左、S=屏幕下、D=屏幕右`，镜头旋转后也保持这一画面语义；长按重复的延迟和速度可调，也可关闭。
- 鼠标点击相邻格等同一步移动。
- 远距离自动行走只用于已探索安全的实地探索区域；显示路径、再次确认，遇到新信息或风险立即停止。
- 鼠标和键盘均可旋转镜头、缩放、回正和切换高度层；镜头操作不推进世界步。
- 方块工具支持快捷选择、鼠标指向或光标移动、层高、旋转、确认、取消和回收。
- 动作一旦提交就完成整次结算，不能中途取消；连续输入不跨越风险边界缓存。
- 所有操作可重绑；支持主键、备选键和鼠标侧键。
- macOS不得把Command、Option或Control组合设为任何功能的唯一输入；提示始终读取当前绑定。

最终默认键位属于可由实现直接确定的常规细节，但首个可玩版本必须覆盖所有功能并通过双平台键位冲突检查。

## 8. 保存、外出与失败

### 8.1 存档

- 除不可中断结算和锁定镜头演出外允许手动保存。
- 存档精确记录角色格位、生命、背包、资源、方块、敌人、机关、任务和持久地图状态。
- 地图切换、任务节点、重大消耗、融合确认和安全出口前后建立轮换自动存档。
- 玩家可以读取旧档回到该存档记录的规划状态。读档属于显式提交边界：撤销历史是瞬态运行状态，不写入存档，也不会从存档恢复；读档完成后清空撤销历史，并以载入状态作为新的基线，不能通过撤销返回读档前状态。
- 自动存档轮换固定为8份；提供6个手动槽，支持缩略图、游戏时长、章节、地区、存档时间和自定义短名。
- 手动覆盖、返回标题或退出可能丢失进度时必须确认，默认焦点在取消。
- 第9章保留独立、不可被轮换覆盖的最终行动前存档。

### 8.2 外出段

进入任务现场建立入口快照。生命和消耗在整个外出段内持续，切换区段不会刷新。

- 安全出口：完成当前结算，归还可回收方块，清理本地临时方块，提交融合／消耗／环境变化，发放奖励并自动保存。
- 主动撤退：整个外出段恢复到入口快照，不保留途中收益或损失。
- 返回据点：一格工坊和六个主要聚落可免费恢复至满生命；安全点本身不治疗。

### 8.3 失败

- 路线规划：优先撤销致败一步；跨越提交节点时恢复最近安全或入口快照。
- 机关解谜：撤销致败操作或重置当前房间；其他已完成房间保持。
- 叙事紧迫段：返回局部检查点，已看演出可跳过。
- 生命归零表示本次行动无法继续，不表现死亡。
- 失败不扣方币、材料、永久成长、方块耐久或任务进度。
- 连续失败只解释原因并突出玩家已知的替代资源／路线，不自动降难，也不提示隐藏内容。

## 9. 难度与辅助

全游戏只有一套标准平衡，不提供简单／普通／困难、动态难度或敌人数值倍率。

可随时修改且不影响奖励、完成度和存档标记的辅助：

- 导航：精简、标准、加强三档。
- 机关三级提示，玩家主动请求。
- 路线汇总：只计算玩家手动选择且信息已知的路线，不自动选路或配装。
- 战斗演出加速／瞬间结算。
- UI与字幕缩放、背景透明度和高对比。
- 色觉预设；颜色信息始终有形状、纹理、图标或文字冗余。
- 全按键重映射、长按／切换互换、鼠标灵敏度。
- 关闭镜头晃动、闪烁、动态模糊，降低粒子和重复提示。
- 完整字幕、声音字幕、对话历史、近期语音重播、单声道和对白增强。

如果测试发现多数玩家无法完成，应调整唯一标准数值或信息表达，不用新增简单模式掩盖问题。

## 10. 三级机关提示

1. **目标提示**：指出尚未满足的目标或遗漏的可观察对象，不说明解法。
2. **关系提示**：标出相关机关、线路、区域和需要利用的规则关系。
3. **行动提示**：依据当前房间状态给出下一段合法操作；若无法可靠衔接，先询问是否重置。

提示通过同行自然台词、图形标记和文字共同表达；不自动弹出，不减少奖励，也不记录“使用提示惩罚”。

## 11. 任务与记录体验

- HUD同时追踪一项任务，可隐藏；日志不限制同时接受数量。
- 日志保存目标、已知事实、相关人物、地点和已完成步骤摘要。
- 长时间未玩后可主动查看“此前剧情”和“当前应做什么”，不强制播放。
- 日志和档案只记录洛尔已经知道的内容，不提前写入最终真相。
- 对话中可查看本次历史；重要剧情结束后写入记录，普通环境闲聊不永久收录。
- 已完成对话和配音可回看／重播。

## 12. 体验验收

- 新玩家无需外部攻略即可在60分钟内掌握基础循环。
- 每种有效、无效、危险、可回收和永久融入状态完成首次教学后的5分钟内，玩家能独立辨认其含义。
- 路线规划的未知信息规则不会诱导不可逆盲猜。
- 地图不泄露未发现内容，同时玩家不会因无小地图频繁迷路。
- 全游戏可用标准键盘＋鼠标组合完成；完整重绑后提示正确更新。首发不额外承诺纯键盘或纯鼠标单设备通关。
- 中日文本长度、字体、字幕和对话历史在相同功能区域内均可用。
- Windows与Apple Silicon macOS读取同版本存档时，玩法状态与内容结果一致。
