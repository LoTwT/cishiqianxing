# 01｜产品愿景与范围

## 1. 产品定位

类型：单人、叙事驱动、确定性方格冒险。\
视角与表现：风格化3D世界，底层为整数方格规则；三种行动区段使用不同信息密度和当前概念镜头。\
核心参考来源：开服时期《绝区零》监视器阵列的格点事件与信息组织、《魔塔》的可计算资源路线、《冒险岛2》和《我的世界》的方块空间感；成品不得复刻参考作品的世界包装、术语、界面或资产。

目标体验不是“在方格上战斗”，而是：先理解规则与成本，再用有限工具把一条危险但确定的局面改造成可行路线。

## 2. 目标气质

锁定关键词：**童话、二次元、有趣、轻松、治愈**。

- 世界有公共设施、学校、商店、交通、职业与跨地区机构，生活形态接近温和的现代社会。
- 方块建筑、自然地貌和古代工程带有童话式想象力，但规则保持清晰。
- 故事允许灾害、受伤、失误、历史断层和制度冲突，但不以残酷、血腥、末日绝望、恐怖或频繁牺牲推动情绪。
- 幽默来自人物性格、工作日常和认真处理小问题，不靠连续玩梗、恶搞世界规则或角色降智。
- 主要情绪终点是道路恢复、居民重新生活、人物学会修正方法，而不是击杀强敌或成为救世英雄。

## 3. 四个产品支柱

### 3.1 可计算的冒险

- 地图、敌人、机关、掉落、危险和战斗均为固定数据。
- 玩家在重要行动前看到足以判断结果的信息；未知信息可以通过亲自观察或勘测获得。
- 不使用随机伤害、暴击、闪避、随机掉落、随机地图或动态敌人缩放。
- 优秀规划的回报是少损耗、更多选择和更稳定的世界状态，而不是评级或排行榜。

### 3.2 有限造格

- 玩家可以用24种蓝图制造实体方块，搭路、支撑、布线、恢复、维护、勘测和临时强化。
- 改造受材料、背包槽位、支撑、邻接、接口、权限和生命周期约束。
- 普通试摆可回收；只有明确公共工程位经确认后才永久融入环境。
- 本作不是无限采集、无限搭建、破坏任意地形的沙盒。

### 3.3 同一世界的三种行动

- 路线规划区段回答“走哪条路、承担什么代价”。
- 机关解谜区段回答“怎样让规则成立、让设施恢复”。
- 实地探索区段回答“这里发生了什么、为什么要行动”。
- 三者共享人物、位置、任务、设施和世界状态，不能呈现为三个不相干的小游戏。

### 3.4 固定而真诚的故事

- 洛尔是唯一叙事中心，有完整固定人格、台词和人物弧。
- 阿莉娅是主要搭档，不是第二主角；两人为专业伙伴和挚友，不设恋爱线。
- 没有主线分支、多结局、善恶值、好感度或隐藏真结局。
- 玩家选择体现在路线、方块布局、机关解法和内容完成顺序，而非改写人物人格与世界真相。

## 4. 目标玩家与游玩节奏

面向喜欢以下体验的玩家：

- 愿意观察地图并进行小整数计算，但不想承受随机失败；
- 喜欢解谜、探索、轻剧情和持续世界变化；
- 喜欢二次元角色与温暖世界，但不要求动作战斗；
- 希望可以随时暂停、思考、撤销或分段游玩。

节奏原则：

- 日常探索、调查与人物交流负责呼吸感。
- 路线规划产生“资源是否值得”的思考压力，不产生手速压力。
- 机关解谜允许长时间思考、无限撤销和主动提示。
- 重大阻拦采用观察—准备—一次结算，而非长时间动作Boss战。
- 大型路线规划图通常以45–70分钟为内容预算，并拆成15–25分钟可安全中断的规划单元。

## 5. 首发范围

### 5.1 包含

- 九章固定主线与可操作尾声。
- 六个半开放地区、一格工坊及独立任务现场。
- 三种行动区段、24张蓝图、与九章节奏配合的固定工具能力、确定性战斗与固定成长。
- 16条实质支线、4张可选规划图、9个短谜题、3次特殊远征。
- 固定世界状态、结局后继续游玩、完成度清单。
- 简体中文与日语文本、字幕和配音。
- Windows PC与Apple Silicon macOS双平台首发，键盘与鼠标操作。
- 离线单人体验和本地存档。

### 5.2 明确不包含

- 实时动作战斗、QTE、跳跃平台、自由攀爬或第一人称玩法。
- 无缝开放世界、随机生成、Roguelite循环、刷怪、经验等级或装备掉落。
- 联机、多人协作、竞技、排行榜、账号体系或服务器依赖。
- 抽卡、付费货币、广告、战令、每日任务、限时活动或重复经济产出。
- 恋爱、好感度、主线选择分支、多结局、二周目专属真相。
- 自由破坏世界、无限采集、无限建造或用户生成关卡。
- 主机、移动端与手柄首发支持；这些不承诺也不作为第一版阻塞项。
- 除已锁定的免费定价外，发布渠道、商店页面及其他发行方案；渠道选择在产品可用后再处理。

## 6. 内容与时长目标

| 层级 | 目标 |
|---|---:|
| 主线 | 22–26小时 |
| 主线＋大多数支线 | 30–35小时 |
| 首次完成全部固定内容 | 约38–45小时的制作预算区间 |
| 可选内容 | 开放后永久保留，不要求在最终章前清空 |

时长是关卡与制作预算，不是对玩家速度的承诺，也不设置计时评价。

## 7. 平台、发行与商业边界

- 首发平台锁定为 Windows PC 与 Apple Silicon macOS。
- 两个平台从首个垂直切片起并行构建与验证，不能把macOS适配留到末期。
- 首发输入锁定键盘和鼠标；所有功能均可重绑。
- 游戏免费；唯一货币“方币”只存在于游戏内，不可购买。
- 单机离线即可完成全部内容，不以云存档、联网验证或在线服务作为必要条件。
- 发布商店与渠道属于阶段延期：负责人为用户，触发门槛为进入Gate I，即候选发行版本已通过全内容、双平台与无障碍验收。
- 任何签名、公证、开发者账号、商店费用、音乐／字体／演员授权和外包合同，都在发生不可逆支出前由用户确认。

## 8. 开发组织前提

- 核心开发人员为用户一人，使用AI协助设计、代码、资产准备、测试和文档。
- 设计不因单人开发而改成极短演示版；按正常完整流程推进，并在各领域出现实际风险时反馈和安排。
- 内容通过模块化方格、共享规则、复用地区资产、固定数据表和自动校验控制复杂度。
- 不以“以后可能有团队”为前提引入无法由当前流程验证的系统。

## 9. 成功标准

首发版本至少同时满足：

1. 玩家在第一小时内理解一步一格、放置方块、战斗预览、基础机关、制作与存档。
2. 三种区段各自可辨认，又能被感知为同一段连续冒险。
3. 路线规划存在真实取舍，不鼓励清空全部敌人。
4. 机关解谜允许多个合法解，提示与撤销不会惩罚玩家。
5. 玩家在不知道最终真相时也能理解前期角色为何作出当时选择。
6. 结局完成“修复也可以是安全变化”的主题，并能返回更新后的世界继续游玩。
7. 中日文本、配音、术语、字幕、版面与信息量对等。
8. Windows与macOS的存档、输入、显示、性能和内容行为一致。
