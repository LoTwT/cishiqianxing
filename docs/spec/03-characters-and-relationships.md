# 03｜角色与关系

## 1. 角色结构原则

- **中央主角＋按剧情需要配置配角**：洛尔始终是唯一叙事中心；没有必要的角色不为凑队伍而增加。
- 全游戏以洛尔为持续操作角色；除洛尔外，只有阿莉娅拥有本Spec列明的短暂操作段，不建立多角色养成、编队或换人战斗系统。后续不得仅为凑人数增加可操作角色。
- 不同区段操作不同角色时，切换必须有剧情原因、明确交接和固定结束点。
- 只有洛尔拥有持续属性、背包、蓝图、工具与永久成长。
- 临时操作角色使用预设能力和公开状态，不需要培养，不会造成“漏养”。
- 同行者通常只作视觉跟随，不占格、不触发压力板、敌人或机关；只有明确双人段落才转为真实规则角色。

## 2. 核心角色

### 2.1 洛尔／ロアル

| 项目 | 设定 |
|---|---|
| 年龄／性别／种族 | 20岁，男性，人类 |
| 出身 | 晴野普通家庭；父母健在，住在另一普通聚落 |
| 身份 | 一格工坊正式学徒、年轻方块技师、本作唯一主角 |
| 可操作性 | 绝大多数玩法和最终行动的操作角色 |

固定性格：温和、好奇、务实、行动力强，带自然轻幽默；主动说话并表达判断，不是沉默玩家替身。

能力与局限：

- 擅长观察空间关系、快速试做和依据现场反馈修改方案。
- 已能独立处理普通委托，但尚未取得高级技术资格。
- 不是全能天才；历史、制度、证据和跨地区影响需要同伴补足。
- 没有失忆、神秘血统、隐藏王族、预言身份或天生超能力。

人物弧：

1. 认为维修就是把错位方块放回原位。
2. 发现多个历史布局都曾让居民正常生活。
3. 认识到强行维持局部稳定会把压力转移给其他地区。
4. 理解真正的修复也包括帮助事物安全变化。
5. 主动提出并执行循序更新。

结局后接手一格工坊的日常主理与外勤调度，成为能够承担跨地区现场协调的方块技师；他仍是技术执行者，不因此成为政治领袖。

### 2.2 阿莉娅／アリア

| 项目 | 设定 |
|---|---|
| 年龄／性别／种族 | 24岁，女性，狐类希人／キツネ系シリオン |
| 出身 | 潮织普通混居家庭，无特殊血统或古代遗产 |
| 身份 | 六方院公共设施异常与证据调查员，三年独立调查经验 |
| 叙事地位 | 主要搭档，不是第二主角 |

能力：重建事故时间线、核验档案、保全证据、比较跨地区记录、向居民解释复杂规则。

缺点：

- 前期容易把“程序已经批准”理解成“方案足够正确”。
- 对尚未形成完整证据的现场直觉过于谨慎。
- 遇到矛盾记录时倾向全部核对，偶尔忽略更直接行动。
- 担心被误解时会变得过度正式、解释过长。

她真诚可靠、会明确承认不知道，也有自然的日常兴趣和克制幽默；不采用狡猾、魅惑、恶作剧或动物拟声式狐狸刻板印象。

人物弧：从依赖统一记录，成长为统一取证方法、保留地区环境附录，并让规则能够被事实修正。

可操作边界：

- 第2章约8–10分钟：核验潮织记录与现场差异。
- 第4章约10–12分钟：在机关另一侧检查历史配置并为洛尔开路。
- 第8章约15–18分钟：对照六地记录并完成证据拼合。
- 特殊远征中还有固定短调查段。
- 她没有独立属性、背包、战斗、成长或专属调查系统。

### 2.3 伊尔玛／イルマ

| 项目 | 设定 |
|---|---|
| 年龄／性别／种族 | 52岁，女性，人类 |
| 身份 | 一格工坊导师；前古代公共结构史与失传功能方块工艺学者 |
| 与洛尔 | 教师、雇主和可信赖长辈，不取代洛尔父母 |

硬性背景：伊尔玛过去是一流学者，因此掌握失传技术与历史。她建立过古代标记对照方法、复原安全拆装工序，并证明部分遗构来自不同时代的正常改造。她43岁主动离开全职学术岗位，44岁接手工坊；洛尔15岁开始跟随她学习。

知识边界：她研究的是分散地方遗物，缺少六地同步记录、全锁触发记录和完整退出协议，因此不能在第8章前知道最终真相。

性格与缺点：耐心、温暖、会区分事实与推测；偏好保存古代遗物原状，容易解释过多，习惯独自承担积压工作，也偶尔让学生多绕路。

人物弧：从保存与维持，转为公开记录证据、适用范围和未知内容，并重新连接学术研究与地方维修。

她始终不可操作，不进入常规战斗和谜题队伍，不提供最优路线或谜题答案。结局后仍留在工坊，与已接手日常主理的洛尔共同经营，负责教学、公开研究与疑难复核；她不退休、不死亡、不回到学术高位。

### 2.4 罗兰／ローラン

| 项目 | 设定 |
|---|---|
| 年龄／性别／种族 | 46岁，男性，希人；具体动物谱系属视觉概念基准，未作剧情硬锁 |
| 出身 | 深脊普通家庭，早年参与承重设施封控、疏散和运输恢复 |
| 身份 | 六地区危机协调负责人 |

优势：能快速区分即时危险和可稍后调查的问题，把技术意见转成行动与停止条件，尊重地方专业人员，并在证据达到标准时真正改变决定。

缺点：偏向可量化的眼前安全；时间紧迫时倾向采用既有成功记录的统一措施；容易低估地区细微差异；不喜欢行动长期停留在“继续观察”。

第6章强化决定必须保持合理：当时中央节点快速失稳、通信受威胁、继承手册要求强化，而局部强化确实保护了居民。错误来自失传程序缺少全局压力转移信息。新证据形成后，罗兰立即停止扩大强化、承担责任并开放档案。

人物弧：从统一紧急措施，发展为“中央统一风险接口和安全下限、地方决定具体执行、失联时可安全降级”的公共制度。

他不可操作、无属性或战斗能力。结局后临时总协调权自动结束；继续公共安全工作并主持公开复盘，不辞职、不牺牲、不被脸谱化惩罚。

## 3. 持续地区角色

### 3.1 卡洛／カルロ

- 36岁，人类男性，炉歌公共维护协调员，早年是运输线路维修员。
- 爽朗、务实、说话节奏快，熟悉各维修队能力，也记得居民的小问题。
- 缺点是在压力下把问题压缩为优先级与进度表，忽略执行人员疲劳。
- 人物弧是理解协作不仅是效率，也包括让参与者表达限制和需要。
- 与洛尔由“外来支援”发展为互相认可的同行。

### 3.2 芙兰／フラン

- 48岁，女性熊类希人，余响社区记录保管员。
- 耐心、实在，带克制的干燥幽默；坚持记录标明时间、来源和环境。
- 缺点是很难让已经失效的记录退出日常使用。
- 人物弧是区分“仍在使用”与“值得保存但已经结束”的记录。
- 她不懂调律网完整真相，不代替伊尔玛解释历史，也不提供种族天赋或独立档案玩法。

### 3.3 尤恩／ユアン

- 32岁，人类男性，环庭社区服务协调员。
- 耐心、条理清楚，擅长把复杂规定转成居民可执行步骤。
- 前期认为所有人走同一程序就是公平，后来认识到规则必须依据真实结果修正。
- 他不调查异常、不判断古代证据，也没有危机决策权；他的作用是展示制度中认真服务居民的普通工作人员。

## 4. 六地区人物锚点

| 地区 | 锚点角色 | 剧情职责 |
|---|---|---|
| 晴野 | 伊尔玛 | 技术与生活经验，主角成长的起点 |
| 潮织 | 阿莉娅 | 当地联系、调查与动态路线经验 |
| 炉歌 | 卡洛 | 公共维护、生产协作与现场限制 |
| 深脊 | 罗兰 | 长期安全经验与跨区危机责任 |
| 余响 | 芙兰 | 记录、记忆与允许过去结束 |
| 环庭 | 尤恩 | 规则落地、居民反馈与制度修正 |

每个锚点至少服务当地主线、两项相关可选内容及结局反馈。其他居民只有明确剧情职责时才命名，不为每条支线新增长期角色。

## 5. 角色关系

### 5.1 洛尔与阿莉娅

- 从礼貌合作发展为彼此最信任的专业搭档和非常亲近的私人朋友。
- 洛尔让阿莉娅相信现场经验可以先于完整文书产生价值；阿莉娅让洛尔理解修好眼前问题也必须留下依据并考虑其他地区。
- 允许自然关心、玩笑、默契和互相依赖。
- 明确禁止好感度、告白、情侣身份、嫉妒、占有欲、暧昧选项、情侣式插画与恋爱音乐编码。
- 结局明确两人长期共同工作，不把“未来是否恋爱”当悬念。

### 5.2 洛尔与伊尔玛

- 是共同工作五年的稳定师徒关系，不是命定传承。
- 伊尔玛选择洛尔是因为他愿意观察、试错和承认错误，不是因为天赋或血统。
- 结局后两人逐渐成为资深修理师与独立同行，师生感情保持不变。

### 5.3 阿莉娅与罗兰

- 阿莉娅负责证据是否可信；罗兰负责证据是否足以支持公共行动。
- 两人可以公开质疑彼此，不靠误会、背叛或上下级压迫制造冲突。
- 罗兰不能要求篡改证据；阿莉娅也不能绕过公共安全边界自行作永久决定。

### 5.4 洛尔与罗兰

- 洛尔提出并执行现场方案；罗兰审查公共风险、权限与停止条件。
- 罗兰不会因为洛尔是主角就绕过制度，也不会因中央职位否定现场经验。
- 双方的方法冲突最终由公开验证解决，不演变为私人敌意。

## 6. 角色与玩法硬边界

- 人类与希人使用相同的生命、攻击、防御、速度、背包槽位、格移动和方块规则。
- 身体谱系不能成为主线唯一解；耳、尾、嗅觉等不提供机关、战斗或调查特权。
- 临时操作角色不取得永久成长方块；所有永久成长只为洛尔服务。
- 视觉同行不参与占格和机关判定；双人规则段必须明确切换。
- 配角不替玩家计算最优路线、代解谜题或自动决定方块配置。
- 主线不通过角色死亡、隐藏身份、背叛或恋爱分支制造转折。

## 7. 形象与配音的后续复审

角色身份、年龄、性格、关系与剧情职责已锁定。以下属于概念基准后的制作复审，不改变角色核心：

- 最终脸型、发型、服装拆件、配色、材质、表情与模型拓扑；
- 罗兰具体动物谱系及角形，当前概念图只作暂定方向；
- 阿莉娅包带与五金的一致性；
- 尤恩与洛尔远景轮廓区分；
- 中日两套最终演员声线及真人、合成或混合制作方式。

用户在角色制作稿和声线样带阶段集中确认；不得模仿名人或可识别演员。
